# New Web

This repository contains a Next.js portfolio starter built for Maadhini. It includes:

- App router structure with pages for home, about, projects, blog, portfolio, experience, and contact
- Component boilerplate for layouts, home sections, project/blog listings, and reusable UI atoms
- Theme toggling (light/dark) with persistence
- MDX content support and example posts/projects
- Tailwind CSS configured with dark mode

Use this as the foundation for a personal portfolio and project showcase website.
